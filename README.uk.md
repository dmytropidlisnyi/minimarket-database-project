# 🛒 Реляційна база даних мінімаркету
[Read in English](README.md)

Реляційна база даних, розроблена для мінімаркету роздрібної торгівлі; передбачає автоматизований розрахунок транзакцій і суворі обмеження цілісності даних. Створена як фінальний проєкт для курсу **CS50 SQL**.
## 🛠 Технологічний стек
* **База даних:** SQLite
* **Мова:** SQL (DDL, DML)

## ✨ Ключові особливості
* **Нормалізована схема:** 5 взаємопов’язані таблиці (`categories`, `products`, `customers`, `orders`, `order_items`).
* **Цілісність даних:** Забезпечується через `FOREIGN KEY`, `CHECK`, і `UNIQUE` обмеження.
* **Автоматизована бізнес-логіка:** Тригери для фіксації історичних цін на одиницю товару та автоматичного перерахунку загальних сум замовлень.
* **Продуктивність:** Явне індексування зовнішніх ключів для оптимізації запитів.

## 📄Архітектурні деталі
Щоб детальніше ознайомитися з рішеннями щодо проєктування баз даних, компромісами при моделюванні зв’язків між сутностями та архітектурою тригерів, будь ласка, прочитайте повний файл [DESIGN.md](DESIGN.md).
